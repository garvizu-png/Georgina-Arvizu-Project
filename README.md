# COMP 229: Data Structures

This is a repository containing work for COMP 229 Data Structures. Each worksheet and project will be on a separate branch; you should add your answers directly to the worksheet, underneath the question you are answering. To edit a file on a branch on GitHub (according to Google Gemini):

1. Navigate to your repository on GitHub.com.
2. Switch to your branch by clicking the branch dropdown menu near the top-left of the file list (it defaults to main or master) and selecting the branch you want to edit.
3. Click on the file you want to modify to open it.
4. Click the pencil icon (Edit this file) in the top-right corner of the file view.
5. Make your changes in the text editor.
6. Click "Commit changes..." in the top right.
7. Review your commit message and ensure the radio button for "Commit directly to the [your-branch-name] branch" is selected.
8. Click "Commit changes" to save.

Alternatively, you can use an app such as GitHub Desktop (<https://desktop.github.com/download/>) or GitKraken (<https://gitkraken.com/>); refer to documentation for those apps (or come talk to me) for how to use them.

Once you have completed a worksheet (or section), you will need to open a Pull Request so I can review your answers and give feedback:

1. Navigate to the repository on GitHub.
2. Click on the Pull requests tab near the top of the page.
3. Click the green New pull request button.
4. On the "Compare changes" page, look at the dropdown menus below the title. Ensure the base repository and head repository are set to the same repository.
5. Set your branch targets:
  * base: Choose the branch you want to merge your changes into (e.g., main).
  * compare: Choose the branch containing the new changes you want to bring in.
6. Click Create pull request.
7. Enter a title and description for your PR; in the description/comments, please tag @justinnhli so I will get notified.
8. Click Create pull request again to finalize it.
